## Lo que NO recolectamos

- No se recolectan contraseñas, API keys, tokens de acceso, secretos de producción ni credenciales reales en texto plano.
- No se incluyen secretos de proveedores el repositorio; se usan variables de entorno.
- No se registra información financiera sensible sin la necesidad operativa concreta; cuando aparece, se maneja con restricción y validación humana.
- No se usan más datos personales que los estrictamente necesarios para atender la operación del concesionario.
